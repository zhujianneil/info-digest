## 一、核心投资哲学

### 1.1 三大基石（格雷厄姆传承）
```
┌─────────────────────────────────────────────────────────┐
│                    安全边际                              │
│         (Margin of Safety)                              │
│  ┌─────────────────────────────────────────────────┐   │
│  │ 以显著低于内在价值的价格买入                        │   │
│  │ 即使判断有偏差也不会遭受重大损失                    │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│                    市场先生                              │
│              (Mr. Market)                               │
│  ┌─────────────────────────────────────────────────┐   │
│  │ 市场是服务你的工具，不是指导你的导师                │   │
│  │ 情绪波动创造买入机会，而非风险信号                  │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│                    能力圈                               │
│           (Circle of Competence)                        │
│  ┌─────────────────────────────────────────────────┐   │
│  │ 只投资你真正理解的企业                            │   │
│  │ 知道边界在哪里比扩大边界更重要                    │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

## 二、估值核心概念

### 2.1 内在价值 vs 账面价值
```
┌─────────────────────────────────────────────────────────────┐
│                        价值三角                              │
│                                                              │
│            内在价值         账面价值         市场价格        │
│         (Intrinsic Value)  (Book Value)   (Market Price)    │
│               │                │                │            │
│               ▼                ▼                ▼            │
│         未来现金流的       历史成本的        交易形成的       │
│         折现值            会计记录          当前价格         │
│                                                              │
│         ┌─────────────────────────────────────────┐         │
│         │  巴菲特关注：内在价值 > 账面价值       │         │
│         │  买入时机：市场价格 < 内在价值         │         │
│         │  安全边际：差距越大越好                │         │
│         └─────────────────────────────────────────┘         │
│                                                              │
│         ┌─────────────────────────────────────────┐         │
│         │  透视盈余 (Look-Through Earnings)       │         │
│         │  = 报告盈余 + 持股公司留存收益归属部分   │         │
│         │  更真实反映持股公司的真实盈利能力        │         │
│         └─────────────────────────────────────────┘         │
└─────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────┐
```

```
│                      │                                       │

│                      │    └───────────┘                    │

│   │ 波动=风险│      │    ┌───────────────────────────┐   │
```
